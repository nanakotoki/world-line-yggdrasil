# 开发计划

## 战斗中的状态图

在每场战斗中，允许自动/手动搜索这一场战斗从开始到结束的状态空间。

模组会将状态空间以有向图的形式展示出来，每一个结点表示游戏的一个状态，而每一次操作，比如出一张牌或者用一个药水，是一条有向边。

- 手动搜索的玩家将会自己操作，程序会将玩家探索到过的状态实时展示出来，未探索的状态则不展示；
- 自动搜索将会使用程序自动搜索状态空间，尝试找出最优解，如果不行那就次优解。暴力穷举和各种启发性搜索算法都可以考虑在内。可以注意到，有向环和自环是可能出现的。

此外，在玩家做交互性手动搜索时：

- 应该允许玩家在展示出的结点之中自由穿梭，点击某个结点即可还原游戏状态。
- 如何让结点拥有独特的标识还是个问题，目前的设想是允许玩家手动给结点起有意义的名字，之后应该考虑允许玩家在图中圈点勾画。

## 何谓“更优”的战斗结果

显然，战斗结束后，自战斗开始时失去的生命值（即战损）越少越好。这就是一种局外收益。局外收益包括：

- 生命值（战损，还有例如“再生”效果每回合逐渐回复生命等）。
- 遗物计数（往往认为越大越好，以便下一场战斗时尽快触发这一遗物效果）。
- 金币（一些卡牌可以让你获得金币，还有敌人会抢钱）。
- 牌组（禁忌魔典和偷窃草蜢等，可以改动牌组）。
- 药水（可以选择用掉或者不用，也有卡牌可以生成药水等）。
- 生命上限（卡牌“狂宴”的斩杀，咬人卷轴的攻击等）。
- 卡牌奖励（卡牌“狩猎”的斩杀等）。
- 其他一些我还没想到的局外收益。

不同的人对不同的收益的重视程度是不同的，或许应该提供一个选项，让玩家指明自己的喜好。可能的方法有：

- 让玩家自行为每种局外收益分配权重。
- 或者只是让玩家给它们简单排个序。
- 或者让玩家在不同结局中选一个。
- 其他更好的想法。

## 不考虑全局最优解了

由于整场游戏的全局最优解不具备给人类学习的价值，搜索程序实现起来也极为困难，我们不考虑它。

我们在一场战斗中只考虑本场战斗的事情，顶多如同刚才所说的，考虑一下更优的战斗结果就够了。
